# 인간연합 vs 좀비군단 — Game Design

## 한 문장
작은 인간 부대를 이끌고 전장을 돌파하며 병력을 불리고, 선택으로 군단을 성장시켜 마왕의 좀비 군단과 충돌한다.

## 알파 핵심 루프
10명 출발 → 게이트 선택 → 소규모 좀비 전투 → 두 번째 선택 → 최종 좀비 150마리 → 자동 전투 → 결과.

## 핵심 화면 계약: Screen 3 / Screen 4

### Screen 3 — 초기 런 플레이 화면

이 화면만 보아도 게임의 핵심이 이해되어야 한다.

- 플레이어 군단은 화면 아래에서 위쪽으로 전진한다.
- 플레이어 병사는 반드시 뒷모습 또는 후면 3/4 시점이다.
- 플레이어 병사는 걷기 애니메이션을 가진다.
- 적 군단은 화면 위쪽에서 플레이어를 향해 아래쪽으로 접근한다.
- 적 병사는 반드시 앞모습 또는 전면 3/4 시점이다.
- 양 진영의 이동 방향이 시각적으로 반대여야 한다.
- 궁수는 화살 projectile을 전방으로 발사한다.
- 검사는 근접 검격, 기사는 돌진 충돌을 한다.
- 투사체는 적과 충돌하고 피격·넉백·쓰러짐을 만든다.

### Screen 4 — 게이트 선택 화면

- 플레이어 군단은 화면 하단에 후면으로 표시된다.
- 전방에는 다음 구간 또는 적군이 보인다.
- 초기 게이트는 `+10 민병대` / `×2 군단`이다.
- 병종 게이트는 `+30 검사` / `+10 궁수` / `+10 기사` 3-way 선택이다.
- 선택 즉시 병력·병종·진형·공격 방식이 화면에서 바뀐다.

### 완료 판정

짧은 플레이만으로 아군/적 방향, 병종 공격 방식, 게이트 선택 결과를 이해할 수 있어야 한다. 이 조건 전에는 상점·종족·다수 스테이지 확장을 진행하지 않는다.

## 디자인 원칙
- 조작보다 선택이 중요하다.
- 병력 증가가 화면의 밀도와 전투력 변화로 체감되어야 한다.
- 짧은 2~4분 런, 자동 전투지만 보는 재미가 있어야 한다.
- 게이트는 숫자 우위만이 아니라 병종·강화·리스크를 제공한다.

## 현재 범위
인간 진영, 민병대 표현, 좀비 표현, +10/×2 게이트, 자동 전투, 최종 웨이브, 결과 화면.

## 이후 확장
검사·궁수·기사, 영웅/스킬, 이벤트, 장애물, 데이터 기반 종족·적·스테이지, 영구 성장.
