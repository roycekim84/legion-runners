# Art Guide

- 세로형 모바일, 밝은 전쟁 판타지, 청색 아군 / 회색·보라색 언데드 적.
- SD 실루엣으로 먼 거리에서도 인간과 좀비가 구분되어야 한다.
- 게이트는 청색 발광 프레임, 결과는 금색 강조, 전장은 청록·남색 기반.
- 캐릭터는 동일한 시점과 광원, 투명 배경 스프라이트를 기준으로 제작한다.
- 폭력은 비사실적 판타지 효과로 표현한다.

## 방향성 규칙

- 아군 asset은 후면 또는 후면 3/4 시점만 사용한다.
- 적 asset은 전면 또는 전면 3/4 시점만 사용한다.
- 아군과 적군이 같은 방향을 바라보는 asset은 Screen 3에 사용하지 않는다.
- 모든 병종은 최소 2프레임 이상의 걷기 루프를 목표로 한다.
- 아군 projectile은 화면 위쪽으로, 적 projectile은 화면 아래쪽으로 이동한다.
- 스프라이트 시트는 `back_walk`, `front_walk`, `attack`, `hit`, `defeat` 상태를 확장할 수 있는 기준선으로 제작한다.
