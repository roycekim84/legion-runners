# Roadmap

## Gate 0 — Screen 3/4 전투 핵심 재구축

이 단계가 완료되기 전에는 다음 단계로 진행하지 않는다.

1. 플레이어 후면 걷기 스프라이트와 애니메이션
2. 적 전면 걷기 스프라이트와 애니메이션
3. 양 진영의 반대 방향 전진과 Formation 거리
4. 궁수 화살 projectile 및 충돌
5. 검사 근접 검격, 기사 돌진 충돌
6. 피격·넉백·쓰러짐 상태
7. 플레이어 병종 게이트와 즉시 진형·공격 방식 반영
8. Screen 3 → Screen 4 → Screen 3 전환 Web 테스트

완료 기준: 짧은 플레이만으로 아군/적 방향, 병종 공격 방식, 게이트 선택 결과를 이해할 수 있어야 한다.

## Gate 1 — Prototype

이동, 원근, Formation, 기본 좀비, 자동 전투, 결과, Web 검증.

## Gate 2 — Prototype 2

검사·궁수·기사, 적 역할 차이, 병종 게이트, 영웅 1명.

## Gate 3 — Alpha

10 스테이지, 5종 이상 적, 보스 2종, 이벤트, 영구 성장, 저장·사운드·튜토리얼.

## Gate 4 — 확장

엘프·드워프·수인·용인, 지형과 갈림길, 메타 콘텐츠.
