# Technical Spec

## 스택
- Flutter 3.44 / Dart 3.12
- Flame 1.31
- Web 우선 테스트, iOS/Android 세로 화면

## 구조
`LegionPage`는 HUD와 `GameWidget`을 조합한다. `LegionGame`은 시간 진행, 입력 대상 lane, 전투 수치와 렌더링을 담당한다. `LegionSnapshot`은 게임 데이터와 Flutter UI 사이의 읽기 전용 상태 경계다.

## 2.5D
실제 좌표는 lane과 진행 거리만 사용한다. 도로는 사다리꼴로 그려 원근감을 만들고, 군단은 행 번호에 따라 간격·스케일을 줄인다. 실제 army 수는 표시 수(플레이어 110, 적 90)와 분리한다.

## 전투 방향성과 좌표

- 플레이어 진행축은 화면 아래에서 위쪽이다.
- 플레이어 Formation은 후면 스프라이트, 적 Formation은 전면 스프라이트를 사용한다.
- 양 진영은 서로 반대 방향으로 전진한다.
- 전투는 군단 간 거리와 projectile world position으로 판정한다.
- 병력 숫자만 주기적으로 감소시키지 않고 접근 → 사거리 공격 → 접촉 → 피격·넉백·사망을 거친다.

## 병종 공격 계약

| 병종 | 표현 | 공격 오브젝트 | 판정 |
|---|---|---|---|
| 민병대 | 후면 보병 행군 | 근접 무기 | 접촉 범위 |
| 검사 | 후면 검병 행군 | 검격 arc | 짧은 근접 범위 |
| 궁수 | 후면 활병 행군 | 화살 projectile | 직선 사거리 |
| 기사 | 후면 중장기병 행군 | 돌진 충격파 | 전진 거리+충돌 |
| 좀비 | 전면 보행 | 근접 | 느린 접촉 공격 |
| 스켈레톤 | 전면 보행 | 무기 | 빠른 접촉 공격 |
| 구울 | 전면 보행 | 돌진 hitbox | 고속 충돌 |
| 언데드 기사 | 전면 중갑 보행 | 방패/충격 | 높은 경직 저항 |
| 네크로맨서 | 전면 시전자 | 소환 마법 | 주기적 소환 |

최소 애니메이션 상태는 `walk`, `attack`, `hit`, `knockback`, `defeat`다.

## 성능 원칙
표시 개체 상한, 단순 원/사각형 스프라이트, 군단 단위 전투 tick, 향후 Object Pool과 SpriteBatch를 적용한다.

## 데이터화 방향
`data/` 아래 JSON 또는 Dart immutable definition으로 unit, enemy, gate, stage, race, hero를 정의하고 시스템은 정의를 읽어 실행한다.
